# Сервер обмена сундуками (для онлайн-сборки)

Маленький сервер, через который онлайн-версия `ChestCounter-Online.exe` обменивается точным числом сундуков с напарниками.
Только стандартная библиотека Python 3.8+, без зависимостей.

```
python3 server.py
```

Переменные окружения: `PORT` (8787), `HOST` (127.0.0.1), `DATA_FILE` (`./data.json`), `BEHIND_PROXY=1` (читать `X-Forwarded-For`
за nginx/Caddy), `RETENTION_DAYS` (14). Программы ходят только по **https** (кроме `localhost` для проверки), поэтому
поставь перед сервером обратный прокси с сертификатом.

## Что хранится

Для каждого законченного матча, который отправил игрок: Epic ID, ник, ID матча, время начала, число сундуков (и сколько из них
разрушено), Epic ID живых напарников. Больше ничего: ни наград, ни IP-адресов, ни журнала запросов. Записи удаляются через
`RETENTION_DAYS` дней. Отправка включается в программе галочкой и по умолчанию выключена.

## Как это работает

- `POST /v1/report`: игрок отправляет свой матч. Заголовок `X-Install-Key` — случайный секрет этой установки. Сервер запоминает
  хеш первого ключа, увиденного для Epic ID, и потом принимает этот ID только с тем же ключом (иначе 403), чтобы никто не мог
  перезаписать чужие данные.
- `GET /v1/mates?epic=…`: игрок получает числа напарников за свои матчи последних 48 часов. Число отдаётся, только если **оба**
  указали друг друга напарниками в этом матче. Матчи склеиваются по ID матча, а если он у игроков разный, по времени начала
  (в пределах 10 минут).
- Ограничения: тело запроса до 4 КБ, 90 запросов в минуту с одного адреса, до 300 сундуков за матч.

Сервер доверяет игроку в одном: что число сундуков, которое он прислал, настоящее. Epic ID без входа через Epic подтвердить
нельзя, поэтому защита сводится к привязке ключа и взаимному указанию напарников.

## Сборка с адресом сервера

Адрес в репозитории не хранится. Он вшивается в онлайн-exe при сборке:

```
dotnet publish src/ChestCounter/ChestCounter.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:EnableCompressionInSingleFile=true -p:DebugType=none -p:Online=true -p:ServerUrl=https://твой-сервер -o dist-online
```

В GitHub Actions адрес берётся из секрета `SQUAD_SERVER_URL`. Игрок может переопределить его в окне программы.
