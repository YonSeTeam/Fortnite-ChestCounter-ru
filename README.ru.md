# Fortnite Chest Counter — русская версия

**Считает каждый сундук, который ты открыл в Fortnite, матч за матчем, с оверлеем, который вписывается в игру.**

[**⬇ Скачать ChestCounter.exe**](../../releases/latest) · Windows 10 / 11 · бесплатно · без установки

</div>

---

Это русская версия программы [LED-N/Fortnite-ChestCounter](https://github.com/LED-N/Fortnite-ChestCounter) (версия 1.5.1). Весь интерфейс, отчёт, консоль и оверлей переведены на русский; в остальном программа работает точно так же, как оригинал, и подхватывает его данные и настройки.

Chest Counter читает повторы, которые Fortnite сохраняет после каждого матча, и ведёт счёт сундуков, которые ты открыл, а также **сокровищ охоты за сокровищами**, выпавших из твоих сундуков. Прозрачный оверлей показывает счёт прямо в игре.

> Программа считает сундуки, которые открыл **ты**. Она не показывает, где на карте лежат сундуки.

## Как это работает (и почему это безопасно)

Fortnite может записывать **файл повтора** каждого матча на твой ПК. Chest Counter читает эти файлы после окончания матча и больше ничего.

- ✅ **Только чтение повторов**: файлы `.replay` из `%LOCALAPPDATA%\FortniteGame\Saved\Demos` открываются только на чтение и не изменяются.
- ✅ **Никакого вмешательства в игру**: папка установки Fortnite не затрагивается.
- ✅ **Нет доступа к памяти игры**: программа ничего не читает, не пишет и не внедряет в процесс Fortnite.
- ✅ **Данные не отправляются**: нет входа, нет доступа к аккаунту Epic, нет телеметрии. Выход в сеть только на GitHub: за данными охоты за сокровищами и картинками, а также для проверки обновлений.
- ✅ **Ничего не открыто в сеть**: окно показывает страницу, которую счётчик отдаёт только твоему ПК (`127.0.0.1`).

> [!IMPORTANT]
> **В Fortnite должна быть включена запись повторов**: *Настройки → Игра → Повторы → Записывать повторы: **Вкл.***. Без повторов программе нечего читать.

Fortnite записывает ключ расшифровки повтора только по окончании матча, поэтому сундуки подсчитываются **через несколько секунд после матча**, а не во время него.

## Установка

1. Скачай `ChestCounter.exe` со страницы [Releases](../../releases/latest).
2. Запусти его. Если Windows покажет предупреждение SmartScreen (файл не подписан), нажми «Подробнее» → «Выполнить в любом случае».
3. Язык выбирается в **Настройки → Язык → Русский**.

Данные и настройки хранятся в `%APPDATA%\ChestCounter`. Если ты уже пользовался оригинальной версией, они подхватятся автоматически (на всякий случай сделай копию этой папки).

## Обновления

Русская версия проверяет обновления в [релизах этого репозитория](../../releases). Данные охоты за сокровищами и картинки загружаются из репозитория автора, поэтому остаются актуальными.

## Замечания по переводу

- Игровые термины («наряд», «Без строительства», «Джем-трек», «гаджет», «Повторы» и др.) переведены без сверки с русским клиентом Fortnite. Если что-то называется в игре иначе, напиши в Issues.
- Названия недель и уведомления берутся из данных автора и могут оставаться на английском.
